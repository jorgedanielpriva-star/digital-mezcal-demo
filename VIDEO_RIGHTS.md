# Politica de videos

Este archivo puede enlazar videos publicos de YouTube u otros sitios, pero no debe descargar, copiar, recortar ni republicar los videos.

## Uso permitido para demo

- Enlace al video original.
- Resumen breve con atribucion.
- Marcadores de tiempo si son utiles.
- Reproductor oficial embebido solo cuando el video permite insercion.

## Antes de incrustar

Revisar:

- Canal original y autor.
- Descripcion del video.
- Si YouTube permite insertar el video.
- Si el video contiene musica, imagenes o material de terceros.
- Si aparecen productores o comunidades de forma sensible.
- Si el uso es educativo, documental, comercial o promocional.

## Estados recomendados

- `Enlace seguro`: se enlaza al sitio original y no se incrusta.
- `Enlace revisable`: candidato pendiente de revisar derechos y pertinencia.
- `Embebible revisado`: se puede incrustar usando el reproductor oficial.
- `No usar`: no debe incluirse en la demo.

## Regla etica

Aunque un video sea publico, eso no significa que el proyecto pueda usar la imagen, voz o historia de productores para promocion comercial. Para usos comerciales o representacion directa, pedir consentimiento.
